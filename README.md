# Detektif Bahan Ketagihan

Permainan Pendidikan Kesihatan Tahun 2, SK 2.1 dan SP 2.1.1. Tiga misi detektif, 16 soalan/kad bukti, lima nyawa, kuasa detektif, kod pintu, lencana, sijil dan bahan cetakan.

## Main

GitHub Pages menerbitkan kandungan akar branch `main`. Semua fail adalah HTML/CSS/JavaScript dan aset setempat; tiada backend atau build diperlukan.

Nama murid, kemajuan dan rekod respons disimpan dalam storan pelayar peranti sahaja. Tiada data murid dihantar ke pelayan.

## Kemas kini

Kemas kini fail website pada branch `main` dan push ke GitHub. GitHub Pages akan menerbitkan kemas kini secara automatik. Kekalkan fail `.nojekyll`.

## Pengesahan

58 semakan Chrome pada komputer, tablet dan telefon lulus sebelum penerbitan: aliran tiga misi, markah, penalti, empat kuasa, avatar, pad kekunci, sijil PNG/PDF, tujuh bahan cetakan, laporan CSV dan tetapan guru.
